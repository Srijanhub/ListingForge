      Open-Weight AI Setup Guide

      ListingForge is engineered to work 100% locally with open-weight models, protecting your product photos and intellectual property while eliminating cloud API bills.

      How to run 100% locally with Ollama:
      1. Download Ollama from ollama.com
      2. Run a high-accuracy open-weight vision model in your terminal: 
        ollama run llama3.2-vision
        or lightweight: ollama run moondream
      3. ListingForge will automatically detect your local model!
      Built-in Neural Heuristic Engine:

      No Ollama? No problem! The built-in domain knowledge engine immediately generates valid, optimized listings for all 4 platforms without any external downloads or API keys.
